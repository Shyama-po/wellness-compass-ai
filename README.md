# 🌿 Wellness Compass AI

**A Multilingual Mental Wellness Self-Reflection Website**

Wellness Compass AI is a responsive, browser-based website designed to help people reflect on their mental well-being, physical health, social connections, and daily habits through an interactive questionnaire.

The project is built using HTML, CSS, and JavaScript, with support for nine languages to make the experience accessible to a wider audience.

## ✨ Features

* 🌍 **9 Language Options:** English, Hindi, Bengali, Odia, Telugu, Tamil, Malayalam, Kannada, and Marathi.
* 🧠 **Mental Wellness:** Reflect on emotions, stress, mood, and concentration.
* 💪 **Physical Well-Being:** Explore sleep, energy, and general physical well-being.
* 🤝 **Social Well-Being:** Reflect on relationships and social connections.
* 📅 **Daily Habits:** Consider routines and lifestyle habits.
* 📊 **Interactive Results:** View a summary of your questionnaire responses.
* 📱 **Responsive Design:** Designed for desktop, tablet, and mobile screens.
* 🔒 **Privacy-Focused:** Answers are processed in the browser and are not uploaded to a server by this version.
* 🆘 **Safety Information:** Includes guidance for seeking help in a crisis.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser.

Alternatively, install the **Live Server** extension in Visual Studio Code, right-click `index.html`, and select **Open with Live Server**.

## 🎯 Project Objective

The objective of Wellness Compass AI is to provide an accessible digital tool for personal wellness reflection. It encourages users to think about their feelings, lifestyle, relationships, and general well-being.

## ⚠️ Disclaimer

Wellness Compass AI is an educational self-reflection tool. It is not a clinically validated psychological screening instrument, does not provide a medical diagnosis, and cannot replace a qualified mental health professional.

Questionnaire results should not be used to determine whether someone is safe from suicide or self-harm. If you are in immediate danger, contact local emergency services or seek help from a trusted person or qualified professional.

In India:

* **Emergency services:** 112
* **Tele-MANAS mental health support:** 14416
